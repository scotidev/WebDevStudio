# WebDevStudio

This is a personal repository for AI instructions focused on web development. It is **not** intended for commercial use.

The repository will be updated and expanded over the long term as new instructions are written.

## Purpose

This repo contains personal instructions for building web applications using AI agentic development. The instructions are organized by area to make them easy to find and follow.

## Structure

| Folder | Description |
|---|---|
| `FrontEnd/` | AI instructions for front-end web development |
| `BackEnd/` | AI instructions for back-end web development |
| `Database/` | AI instructions for database design and management |
